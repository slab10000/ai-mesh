# Context for the remote PDF example

The user wants the PDF generated on the selected destination computer and the
finished files returned to the submitting computer by Mesh.

Follow inputs/pdf-instructions.md. Keep all computation on this destination;
do not delegate or install packages. Write every deliverable inside outputs/.

Include this exact context marker in the PDF: PDF_HANDOFF_42

Use the destination's actual hostname in the document and in generated-on.txt.
Do not claim that delivery has already happened: Mesh collects outputs after
the job completes.
